## 검색 의도 → 콘텐츠 → CTA

1. 불안 해소: “부작용은 무엇인가요?” → 의료진 검토 FAQ → 안전 기준 확인
2. 정보 탐색: “회복기간은 얼마나 걸리나요?” → 당일·1주·1개월 타임라인 → 회복 과정 보기
3. 비교·검토: “자연스러움의 기준은?” → 판단 기준 3가지 → 전문의 상담 신청

## 우선순위

### 1. 증거를 먼저 만든다

광고 문구를 따라가기보다 자격, 진료 과정, 회복 안내, 개인정보 보호를 랜딩 페이지에 구조화한다.

### 2. 경쟁사의 프레임을 바꾼다

‘가장 많이 했다’는 주장에 같은 숫자로 맞서기보다, 환자가 상담 전에 판단할 수 있는 기준을 제공한다.

### 3. 콘텐츠를 AI가 인용하기 쉬운 단위로 쪼갠다

각 질문에 짧은 결론, 근거, 의료진 검토자, 업데이트 날짜를 붙이고 관련 질문을 내부 링크로 묶는다.

## 측정 이벤트

- GEO 영역 점수와 스냅샷 ID
- 질문별 브랜드 인용·언급 여부
- 경쟁사 광고 발견일·집행 기간
- 키워드 검색량·현재 순위·콘텐츠 발행일
- 랜딩 CTA 클릭·상담 시작·상담 완료

GEO 점수는 마케팅 성과의 대체 지표가 아니라, 검색·콘텐츠·전환 개선의 진단 신호로 사용한다.
