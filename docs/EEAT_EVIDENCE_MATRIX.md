# E-E-A-T 증거 매트릭스

## 핵심 원칙

E-E-A-T는 “좋은 사이트인가”를 한 번에 맞히는 분류기가 아니다. AI가 답변 재료로 사용할 때 확인할 수 있는 증거를 관점별로 나누어 수집하는 프레임이다.

| 관점 | 의료 서비스에서 확인할 증거 | 오탐 방지 |
|---|---|---|
| Experience 경험 | 실제 상담·진료 과정, 구체적 사례, 회복 타임라인, 환자 질문에 대한 1인칭 관찰 | 자격 키워드를 경험 점수로 사용하지 않음 |
| Expertise 전문성 | 의료진 실명, 전문 분야, 자격·경력, 공식 프로필, 검증 가능한 소속 | `작성자: 관리자`·`운영팀`을 저자로 세지 않음 |
| Authoritativeness 권위성 | 학회·공공기관·주요 언론·공식 외부 프로필, 브랜드 밖의 일관된 언급 | 단순 링크 수가 아니라 출처의 맥락을 확인 |
| Trustworthiness 신뢰성 | HTTPS, 연락처, 개인정보처리방침, 이용약관, 수정일, 진료·광고 고지 | 본문 정제 과정에서 footer 근거를 제거하지 않음 |

## 하이스트비뇨기과 콘텐츠 체크리스트

- 의료진 이름·직함·전문 분야가 글마다 일관되게 보이는가?
- `Person` JSON-LD의 `sameAs`가 공식 프로필로 연결되는가?
- 수술 실적을 말한다면 산출 기준·기간·범위를 함께 설명하는가?
- 부작용·회복기간·적합성 판단 같은 환자 질문에 직접 답하는가?
- 광고에서 주장한 메시지와 랜딩 페이지의 근거가 일치하는가?
- 상담 비용, 개인정보 보호, 진료 전 확인사항을 CTA 이전에 안내하는가?
- 의료 정보와 후기·사례를 명확히 구분하는가?

## JSON-LD 초안 방향

```json
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "의료진 실명",
  "jobTitle": "비뇨의학과 전문의",
  "worksFor": { "@type": "MedicalClinic", "name": "하이스트비뇨기과" },
  "sameAs": ["공식 프로필 URL"]
}
```

실제 배포 전에는 의료진·기관 정보의 정확성과 의료광고 관련 검토가 필요하다. 이 문서는 구현 프레임이며 의료적 효능을 보증하는 문서가 아니다.
